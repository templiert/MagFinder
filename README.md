## Install
In your Fiji install, create a folder `mag_finder` inside the `plugins` directory and copy the following:

```
Fiji/ or Fiji.app/
└── plugins/
    └── mag_finder/
        ├── MagFinder_.py
        ├── cfg.py
        └── src/
```
Then start Fiji. Run via Plugins -> mag_finder -> MagFinder.
